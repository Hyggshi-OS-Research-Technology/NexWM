# The HDE login screen — who made it

* **Theme (the QML of `Main.qml` and `components/`, `theme.conf`, `metadata.desktop`, `install.sh`,
  `tools/make-background.py`, `tests/sddm-test.sh`)** — Hyggshi OS Research Technology, written for the Hyggshi
  Desktop Environment (HDE); MIT, like the rest of NexWM (see the LICENSE at the root of the repository).
* **The greeting contract the theme follows** — SDDM (the Simple Desktop Display Manager) and its components: the
  `metadata.desktop` keys, the context objects (`sddm`, `userModel`, `sessionModel`, `screenModel`, `keyboard`), the
  `--test` mode and the theme directory layout. No file of SDDM or of any of its themes is copied here: the widgets of
  this theme are drawn in `components/` with plain QtQuick, and the screen's layout (a card in the middle with the logo,
  the users, the password field and the power buttons) is what every login screen does.
* **The background** (`assets/background.png`) is generated by `tools/make-background.py`, which was written for this
  theme: the picture is deterministic (the same bytes from the same numbers), the palette is HDE's (dark blue-black with
  HDE's accent), and no image library or stock picture is involved.
* **`assets/screenshot.png`** is a picture of this theme itself (taken from the greeter), not of anything else.

If you take this theme somewhere else, keep this file and the repository's LICENSE with it.
